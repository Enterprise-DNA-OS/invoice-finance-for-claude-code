Run `npm run finance -- position --json`, `npm run finance -- attention --json` and `npm run finance -- exposure --json`. Write a one-page review to drafts/weekly-review-<date>.md: funds in use and available, each over-advance and its cause, money held by clients, verifications and schedules waiting, debtors over limit, registrations and reviews due. Plain sentences, numbers in tables. Never sent from here.
